## Presentation inside the bedroom

The computer becomes a coherent late-1990s desktop with clear entries into Products, Open Source and Experiments. Opening Open Source launches a software catalogue inspired by period shareware libraries: recognisable covers and logos, a readable list/detail view and generous product previews. Avoid adding fifteen more tiny folders to the current crowded grid.

Each project gets a concise explanation of its purpose and intended user, a real visual walkthrough, Josh's specific contribution, relevant technical decisions, a working source link and its licence. Add demo/install/documentation links where verified. Commercial case studies retain their budgets, audience and revenue results; released tools demonstrate utility, execution and contribution through the actual code and product.

The first visual candidates to develop are Pocket-T, Docshare, LinkHub, Ambassador Kit, Blueballs and the Buzz contribution. Every public project remains in the browsable catalogue. This ordering is a presentation decision, not a reduction of scope.
