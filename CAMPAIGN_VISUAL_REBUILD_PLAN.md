# Campaign Visual Rebuild Plan

Status: active production blueprint

## Objective

Turn the TV/campaign section into a complete evidence-led case-study system. Every important case must have a credible visual story. Use source material first, faithful reconstruction second, generated imagery third.

## Non-negotiable evidence hierarchy

1. **Original evidence first** — supplied screenshots, decks, reports, logos, brand assets, social/community screenshots, product UI, campaign collateral and video.
2. **Faithful reconstruction second** — when a historical site/product no longer exists, rebuild a representative interface from surviving source material and label it as a portfolio reconstruction.
3. **Generated imagery third** — use only for supporting brand/lifestyle/compositional imagery where no original usable visual exists.
4. **Never generate fake proof** — generated or rebuilt work must never be presented as a historical screenshot or measured outcome.
5. **Current brand replaces obsolete brand** — EFFEX is superseded by NextCurrency and should not remain as a standalone current portfolio brand.

NTT becomes a featured deal inside the case, not the entire case.

- Earlier occupancy-planning SaaS product as the origin story.

### Visual build
1. Hero: `US$100M / 7 markets / 250+ delivery / 18 products`.
2. APAC operating map with market / team / delivery structure.
3. Product portfolio wall grouped by decision/problem:

# Website changes required

## Campaign data model
Extend campaign records so visuals are not forced into one generic gallery model. Support:

- `visualType`: `original`, `reconstruction`, `generated`, `mixed`
- `evidence`: historical screenshots / report cards
- `reconstruction`: rebuilt UI screenshot set
- `gallery`: campaign creative
- `caption`: explicit provenance per asset
- `featuredDeal`: for CBRE/NTT and similar nested stories
- `sections`: optional heavyweight case sections

## Case renderer
Heavyweight cases need richer modules than the current single pattern:

- product/interface strip
- evidence strip
- system/architecture diagram
- timeline
- operating dashboard
- client/account logo wall
- featured-deal block
- before/after or funnel view

Campaign cases can retain the existing concise case anatomy.

# Acceptance criteria per case

A case is not complete until:

- Brand/logo is correct for the historical period.
- Hero is high resolution and properly cropped on desktop and mobile.
- At least one meaningful visual appears before long body copy.
- Visuals are relevant to the actual work described.
- Original versus reconstructed versus generated material is labelled accurately.
- Metrics distinguish campaign-attributed outcomes from company/platform outcomes.
- No broken image references.
- No generic filler imagery.
- Case works at desktop and 390px mobile width.
- TV thumbnail is visually strong enough to identify the case at a glance.

# Immediate implementation target

Start with **Coliseum**. It is the best pilot because the supplied source set includes brand, product, Telegram, communities, operating reports, growth framework and historical visuals. Build the reusable heavyweight-case visual modules while reconstructing Coliseum, then reuse those components for JEDSTAR and CBRE.
